# Comparison with python-evtx

Fixture: three in-memory events (Application 1000/1001, Security 4624) generated by `write_events`.

| Check | python-evtx 0.7.x | MoonEvtx 0.1.0 |
| --- | --- | --- |
| File size | 69632 bytes | 69632 bytes |
| Records | 3 | 3 |
| EventIDs | 1000, 1001, 4624 | 1000, 1001, 4624 |
| Record sizes | 896, 888, 888 | 896, 888, 888 |
| TimeCreated | `2024-03-09 16:00:00+00:00` | same with `TimeStyle::PythonEvtx` |
| Header/chunk CRC | `verify() == True` | `EvtxFile::verify` Ok |
| XML | `Views.evtx_record_xml_view` | `EvtxRecord::xml` matches that layout |

MoonEvtx does not wrap Win32 Event Log APIs. It is a file codec, so it also runs on wasm-gc/js.
